# 00 — READ ME FIRST

## Purpose
This pack is designed for maximum Claude Code autonomy and minimum developer interpretation.

It is a **fresh V2 build**. V1 may provide branding, content, useful code, integrations and migration data, but V2 architecture is defined here.

## Human developer role
The developer primarily:
- supplies repo/infrastructure access;
- creates/configures external accounts;
- supplies secrets securely;
- reviews architecture at gates;
- approves production deployment/migrations;
- handles DNS/external-provider/account issues Claude cannot.

The developer should not be required to translate product ideas into technical instructions.

## Product-owner role
The product owner approves:
- fees;
- legal/customer terms;
- final UI feel;
- business policies;
- launch readiness.

Unknown business values should become configuration, not development blockers.
