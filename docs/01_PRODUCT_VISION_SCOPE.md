# 01 — PRODUCT VISION & SCOPE

## Vision
Build a world-class multi-category asset exchange for Sri Lanka with international buyer capability.

Singha combines:
- premium auction-house presentation;
- marketplace discovery;
- live bidding;
- omnichannel communication;
- institutional transparency;
- AI customer/asset intelligence.

## Asset classes
- Vehicles
- Machinery & equipment
- Gems & jewellery
- Property
- Business/commercial assets
- Stock/bulk inventory
- Agriculture/produce
- General assets

Categories must be extensible without core-schema rewrites.

## Sale modes
First-class:
- Timed Online Auction
- Expression of Interest
- Buy Now
- Make Offer
- Sealed Tender
- Live / Hybrid Auction

Future:
- sequential/group timed;
- commodity flows;
- absentee/portfolio autobid.

## Buyer journey
Discover -> Watch -> Ask -> Inspect -> Verify -> Bid/EOI/Offer -> Win/Accepted -> Pay -> Collect/Deliver -> Return.

## Seller journey
Onboard -> Submit/List -> Approval -> Publish -> Interest/Bidding -> Sale -> Settlement -> Analytics.

## Staff journey
Ingest -> Verify -> Enrich -> Publish -> Operate -> Reconcile -> Release -> Settle -> Report/Audit.

## Homepage
Modern, simple, artistic and lightweight:
1. Header
2. Premium hero
3. Featured items only
4. Featured auction/event
5. Category entry
6. Market Pulse
7. Trust/Why Singha
8. Seller/institution CTA
9. Footer

The full catalogue belongs under catalogue/category/search pages.

## Core principles
- serious transparent commerce, not casino-style gamification;
- mobile-first and professional desktop;
- AI assists; deterministic services decide bids/money/permissions/release;
- important commercial actions are reconstructable;
- external providers are replaceable.
