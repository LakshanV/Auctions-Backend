# SINGHA ID / DASHBOARD / CONTROL CENTRE / FRONTEND / SEO

## Singha ID
Extend current Customer; no country-specific accounts.
Add/preferences as needed:
country/residency, preferred display currency, language, timezone, company roles, KYC, seller/bidder verification, dealer/import/export licences, notification preferences.
Verification is capability-based: browse broadly, verify more only when an activity requires it.

## Dashboard
One customer-centric timeline/command centre.

Buying: Watching, Offers, Counters, Active Bids, Awarded/Won, To Pay, Paid, Shipping, Pickup, Completed.
Selling: Draft, Pending, Live, Offers, Tenders, Auctions, Sold, Settlement.
Procurement: RFQs, Supplier Responses, Tenders, Orders.
Logistics: Quotes, Booked, In Transit, Ready, Delivered.
Documents: invoices, receipts, contracts, certificates, shipping/export docs.

## Control Centre
Operators, Markets, Locations, Currencies, FX, Ports, Shipping, Sale Methods, Offers, Auctions, Tenders, RFQs, Supply Programmes, Categories, Units, Fees, Tax/Compliance Rules, Users/KYC, Content/SEO, Audit.

Protected records must be operator-scoped.

## Frontend
Preserve current V3 cinematic visual system, Flow, animated Singha logo, responsive shell and screenshot testing.

Reframe public navigation toward:
Explore / Exchange / Sell / Wanted / Services.

Universal cards must naturally represent vehicle, produce, scrap, gem, machinery or property and show:
title, price/offer state, qty/unit, location, sale method, shipping/trade term, deadline when relevant, CTA.

Item page answers what/qty/location/currency/method/action/shipping/pickup/port/freight/operator without clutter.

Location control = All Locations + filters.
Display-currency selector separate.
Never force IP geography.

## Local sites + SEO
Local sites are marketing/SEO/service entry points that route into central inventory with filters.
Use canonical URLs, hreflang where appropriate, structured data, category/location landing pages and international sitemap architecture.
Do not duplicate listing URLs merely for display currency.

Build a customer-facing language/glossary audit to flag misuse such as "Auction Account", "Auction Shipping", "Global Marketplace", while preserving legal/historical names.
